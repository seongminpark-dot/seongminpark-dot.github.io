EST 240: Visual Rhetoric and Information Technology

This website was created as an individual project for EST 240: Visual Rhetoric and Information Technology. It brings together a YouTube analysis, an expertise essay, an AI generated logo process, and a project explanation in one digital portfolio.

My topic is noise cancelling headphones, with a focus on MKBHD’s review of the Sony WH-1000XM6. I chose this topic because noise cancelling technology carries meanings beyond its technical function. It is also connected to focus, silence, mobility, comfort, and control over personal sound environments.

What This Site Includes

The site is organized around four main sections. The YouTube Analysis page provides a short overview of the selected channel, video, visual concepts, and timestamped moments. The Essay page presents the full visual rhetoric analysis of MKBHD’s Sony WH-1000XM6 review. The Logo page documents the AI generated personal logo, the three logo options, the final selected version, and the prompts used to create the designs. The About page explains the author, course, project purpose, design choices, and technology used to build the website.

YouTube Analysis

The YouTube Analysis page summarizes the selected channel, the three Ms, denotation, connotation, metrics, and key timestamped moments.

Essay

The essay analyzes mise en scène, montage, metrics, denotation, connotation, ethos, and visual rhetoric in a technology review video.

Logo

The logo page shows how the SP personal mark was developed through AI prompts, visual revision, and design choice.

Website

The website presents the project as a digital portfolio rather than a plain document, using navigation, cards, spacing, repeated colors, and a consistent page structure.

Why MKBHD and Noise Cancelling Headphones

MKBHD is an effective channel for visual rhetoric analysis because Marques Brownlee presents technology with a highly polished and recognizable visual style. His reviews usually combine clean studio composition, controlled editing, direct address to the camera, product close ups, and calm technical explanation. These choices make the channel useful for studying how trust and authority are created visually.

The Sony WH-1000XM6 review is especially useful because noise cancelling headphones already involve the idea of controlling the surrounding environment. The product promises silence, focus, and comfort, and the video reinforces those meanings through calm pacing, clean product shots, and professional studio design. The review becomes more than a product evaluation because it presents modern technology as a way to organize personal space and attention.

How the Design Follows CARP

Contrast

The website uses a dark navy header against a light background to create a clear visual hierarchy. Important page titles stand out immediately, while the body text remains easy to read.

Alignment

The main body sections use a consistent left aligned reading column. Headings, paragraphs, cards, and information boxes are arranged to keep a stable visual edge.

Repetition

The same navigation bar, footer, color palette, card style, and typography system appear across the Home, YouTube Analysis, Essay, Logo, and About pages.

Proximity

Related information is grouped together. The thesis and video appear near the top of the Essay page, the timestamp examples are grouped on the YouTube Analysis page, and the logo options are grouped together on the Logo page.

Technology Used

This website was built with hand written HTML and CSS and published through GitHub Pages. The pages use one shared stylesheet, which allows the same visual design to appear across the site. The YouTube video is embedded directly into the YouTube Analysis and Essay pages, and the logo images are stored in the same GitHub repository as the website files.

I chose GitHub Pages because it gives more control over layout, spacing, typography, and visual consistency than a template based website builder. This helped me make the project look more like a portfolio site while keeping the structure simple and readable.

Design Identity

The visual identity of the site is based on dark navy, white, light gray, and electric blue. These colors connect to the topic of noise cancelling headphones because they suggest quiet technology, controlled sound, focus, and a premium consumer device. The final SP logo also uses these colors so that the logo and the website feel connected.

The final logo uses a geometric SP mark inside a shield like form. At the denotative level, it shows initials, a geometric outline, negative space, and a small blue sound accent. At the connotative level, it suggests protection, silence, focus, and control over sound. This makes it appropriate for a technology website about noise cancelling headphones.
