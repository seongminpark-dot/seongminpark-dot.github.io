EST 240: Visual Rhetoric and Information Technology

This website was created as an individual website project for EST 240: Visual Rhetoric and Information Technology. The project connects a written expertise essay, a YouTube video analysis, and an AI generated personal logo into one coherent digital portfolio.

My topic is noise cancelling headphones, with a focus on MKBHD’s review of the Sony WH 1000XM6. I chose this topic because noise cancelling technology is not only a technical feature. It also carries visual and cultural meanings related to focus, silence, mobility, comfort, and control over personal sound environments.

What This Site Includes

The site is organized around three main artifacts. The Essay page presents the visual rhetoric analysis of MKBHD’s Sony WH 1000XM6 review. The Logo page documents the AI generated personal logo, the three logo options, the final selected version, and the prompts used to create the designs. The Home page introduces the project and connects all parts of the website through a clear navigation structure.

Essay

The essay analyzes mise en scène, montage, metrics, denotation, connotation, and visual rhetoric in a technology review video.

Logo

The logo page shows how the SP personal mark was developed through AI prompts, visual revision, and design choice.

Website

The website presents the project as a digital portfolio rather than a plain document, using navigation, cards, spacing, and repeated colors.

Why MKBHD and Noise Cancelling Headphones

MKBHD is an effective channel for visual rhetoric analysis because Marques Brownlee presents technology with a highly polished and recognizable visual style. His reviews usually combine clean studio composition, controlled editing, direct address to the camera, product close ups, and calm technical explanation. These choices make the channel useful for studying how trust and authority are created visually.

The Sony WH 1000XM6 review is especially useful because noise cancelling headphones already involve the idea of controlling the surrounding environment. The product promises silence, focus, and comfort, and the video reinforces those meanings through its calm pacing, clean product shots, and professional studio design. The review therefore becomes more than a product evaluation. It becomes a visual argument about how modern technology can organize personal space and attention.

How the Design Follows CARP

Contrast

The website uses a dark navy header against a light background to create a clear visual hierarchy. Important page titles stand out immediately, while the body text remains easy to read. The electric blue accent is used carefully so that it supports the technology theme without overwhelming the page.

Alignment

The main body sections use a consistent left aligned reading column. Headings, paragraphs, cards, and information boxes are arranged to keep a stable visual edge. This is important because alignment makes the site look intentional rather than randomly assembled.

Repetition

The same navigation bar, footer, color palette, card style, and typography system appear across the Home, Essay, Logo, and About pages. This repetition helps the pages feel like one coherent project instead of separate files.

Proximity

Related information is grouped together. The thesis and video appear near the top of the Essay page, the metrics are grouped in one information box, and the logo options are grouped together on the Logo page. This helps viewers understand the relationship between each part of the project.

Technology Used

This website was built with hand written HTML and CSS and published through GitHub Pages. The pages use one shared stylesheet, which allows the same visual design to appear across the site. The YouTube video is embedded directly into the Essay page, and the logo images are stored in the same GitHub repository as the website files.

I chose GitHub Pages because it gives more control over layout, spacing, typography, and visual consistency than a template based website builder. This helped me make the project look more like a portfolio site while still keeping the structure simple and readable.

Design Identity

The visual identity of the site is based on dark navy, white, light gray, and electric blue. These colors connect to the topic of noise cancelling headphones because they suggest quiet technology, controlled sound, focus, and a premium consumer device. The final SP logo also uses these colors so that the logo and the website feel connected.

The final logo uses a geometric SP mark inside a shield like form. At the denotative level, it shows initials, a geometric outline, negative space, and a small blue sound accent. At the connotative level, it suggests protection, silence, focus, and control over sound. This makes it appropriate for a technology website about noise cancelling headphones.

Acknowledgements

This project was developed for EST 240: Visual Rhetoric and Information Technology. The website applies course concepts including visual rhetoric, mise en scène, montage, semiotics, denotation, connotation, metrics, and website design.

The project also reflects the course emphasis on turning analysis into web based communication. Instead of presenting the essay as only a document, the site organizes the essay, video, logo, prompts, and design explanation as connected parts of one digital project.
