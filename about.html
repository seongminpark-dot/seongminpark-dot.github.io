Project Purpose

This website was created for EST 240: Visual Rhetoric and Information Technology. The project analyzes how a YouTube technology review creates meaning through visual design, editing, narration, audience metrics, and logo based identity.

My selected topic is noise cancelling headphones, with a focus on MKBHD’s review of the Sony WH-1000XM6. The project connects consumer technology with visual rhetoric by examining how a product is framed as advanced, trustworthy, and desirable before viewers personally use it.

Website Structure

The website is organized into four main pages. The Home page introduces the project. The Essay page presents the main expertise paper. The Logo page documents the AI generated personal logo and prompts. The About page explains the purpose and design choices behind the site.

Design Choices

The site uses a dark navy, white, light gray, and electric blue color palette. These colors connect to the topic of noise cancelling headphones by suggesting technology, silence, focus, and control. The layout uses clear spacing, repeated cards, and consistent navigation so that the website feels organized and easy to read.

The design also applies basic visual rhetoric principles. The dark header creates contrast, the repeated card structure creates consistency, and the left aligned text supports readability. The goal is to make the website feel like a polished technology project rather than a plain document.
